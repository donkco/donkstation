concrete_drying
/datum/component/concrete_drying

Shared drying component for wet concrete turfs and concrete moulds.

Attach to a wet concrete turf or a concrete mould structure. Dispatches on dry_result type: if it's a turf path, calls ChangeTurf; if it's an obj path, spawns the new obj and qdels the parent.

Vars

dry_resultThe type to transform/spawn when drying completes
dry_timeTime in deciseconds before drying completes
timer_idStored timer ID so we can cancel on early removal

Procs

on_scoopedCancels drying when the wet concrete turf is scooped by a shovel.
