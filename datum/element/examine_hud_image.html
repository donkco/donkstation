examine_hud_image
/datum/element/examine_hud_image

Add this element to an atom to have the ability to show an extra icon when its double-examined. First examine shows examine_hint_text to indicate you can examine more for a detailed image. Image is removed when mouseexit occurs.

Vars

active_viewersAssoc list of mob -> list("appearance_ref" = weakref, "source_ref" = weakref), for active viewers
examine_hint_textText shown on a normal examine to hint the player they can take a closer look.
examine_more_textText shown alongside the image when examine_more is triggered.
hud_iconThe icon file to display on the HUD
hud_icon_stateThe icon state to display on the HUD
pixel_x_offsetHorizontal pixel offset relative to the atom
pixel_y_offsetVertical pixel offset relative to the atom

Procs

on_viewer_deletedsayonara, viewer.
on_viewer_mouse_enteredIf the viewer moves their mouse to another atom, we exit. This is more reliable than using exit in case you double-examined but already fucked your mouse off.
