old_master_painting
/obj/item/old_master_painting

The Old Masters painting, taken down from its frame.

Vars

carrierThe mob directly holding this painting, tracked for directional examine. Null when not held.

Procs

examineWhen the painting is examined on the ground, note if the examiner is approaching from behind.
get_examine_back_textReturns the text shown when the examiner cannot see the front of the painting (carried).
get_examine_front_textReturns the text shown when the examiner can see the front of the painting (carried).
get_examine_ground_back_textReturns the text shown when the painting is on the ground and the examiner faces the back.
on_carrier_examinedFires when someone examines the mob carrying this painting. Appends directional-aware text to the examine list. If the examiner is directly behind the carrier, they only see the back of the canvas.
on_movedTracks when this painting is picked up or put down, so we can register/unregister the examine signal on whatever mob is carrying it.
