vinyl_disk
/obj/item/vinyl_disk

Vinyl record item.

Stores up to two tracks (A side and B side). Activate in-hand to flip between sides when a B-side track is present.

Vars

a_side_icon_stateIcon state shown when the A side is active. Falls back to icon_state if null.
b_side_icon_stateIcon state shown when the B side is active. Falls back to a_side_icon_state then icon_state if null.
b_side_playing_stateIcon state used as an overlay on the vinyl player when B side is loaded. Falls back to playing_state if null.
playing_b_sideWhether we are currently presenting the B-side.
playing_stateIcon state used as an overlay on the vinyl player when A side is loaded.
track_aInstantiated A-side track.
track_a_typeType path of the A-side track datum.
track_bInstantiated B-side track.
track_b_typeType path of the B-side track datum. Null means no B-side.
